┌──────────────────────────────────────────────────────────────────────────┐
│  🧅 INTEGRAÇÃO TOR                                                        │
└──────────────────────────────────────────────────────────────────────────┘

   O que é Tor?
   • Rede de anonimato para bypass de bloqueios
   • Gratuito e open source
   • Roteia tráfego através de múltiplos nós

   Quando usar?
   • Bloqueios de DNS (lovable.dev não resolve)
   • Restrições de rede
   • Anonimização de IP

   Como usar?
   1. Setup automático já oferece instalação
   2. Ou instale manualmente:
      Linux:  sudo apt-get install tor && sudo systemctl start tor
      macOS:  brew install tor && brew services start tor
   3. Configure no .env:
      TOR_ENABLED=true

   Logs mostrarão:
   [INFO] 🧅 Usando Tor (SOCKS5 Proxy)
     host: 127.0.0.1
     port: 9050
